Apa itu CSS Selectors?

CSS Selectors adalah pola yang digunakan untuk memilih elemen HTML yang ingin Anda styling. Selector memungkinkan Anda menargetkan elemen tertentu di halaman web dan menerapkan gaya CSS ke elemen tersebut. Memahami berbagai jenis selector sangat penting untuk menulis CSS yang efisien dan mudah dipelihara.

Jenis-jenis CSS Selectors

p

Element Selector

Memilih semua elemen dengan nama tag tertentu.

p {
  color: blue;
  font-size: 16px;
}
.cls

Class Selector

Memilih elemen dengan atribut class tertentu. Gunakan titik (.) sebelum nama class.

.highlight {
  background-color: yellow;
  padding: 10px;
}
#id

ID Selector

Memilih elemen dengan atribut id tertentu. Gunakan tanda pagar (#) sebelum nama id.

#header {
  background: #333;
  color: white;
}
a b

Descendant Selector

Memilih elemen yang merupakan keturunan dari elemen lain.

nav a {
  text-decoration: none;
  color: inherit;
}

Latihan Praktik

Coba praktikkan selector-selector di atas dengan mengerjakan latihan interaktif di bawah ini. Anda akan belajar cara menggunakan berbagai selector untuk styling elemen HTML.

Poin Penting

  • ID selector memiliki spesifisitas lebih tinggi dari class selector
  • Gunakan class selector untuk styling yang dapat digunakan kembali
  • Hindari penggunaan ID selector yang berlebihan untuk styling
  • Selector yang lebih spesifik akan menimpa selector yang kurang spesifik
